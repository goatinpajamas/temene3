# Temene 3

Grade 12 national exam prep app, experiment 3 of 3: **native SwiftUI**, iOS only.

This is a small spike to compare against the Expo (`temene`) and Capacitor (`temene2`) experiments.

**This repository is public.** It holds only demo questions written for the prototype and app code. Keep past papers, textbook material, API keys and anything that unlocks paid content out of it.
